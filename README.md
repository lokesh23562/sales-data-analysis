# Sales Data Analysis Report

## Project Overview
This project analyzes a sales dataset using Python and the Pandas library.
The goal is to understand sales performance, identify the best-selling product,
and calculate basic statistics such as total and average sales.

## Dataset Description
- File Name: sales_data.csv
- Rows: 100
- Columns: 5
- Contains product-wise sales information

## Tools & Technologies Used
- Python
- Pandas Library

## Setup Instructions
1. Install Python
2. Install Pandas using:
   pip install pandas
3. Run the program:
   python sales_analysis.py

## Data Analysis Steps
1. Loaded the dataset using pandas
2. Checked basic structure and data types
3. Handled missing values
4. Calculated sales metrics
5. Identified the best-selling product

## Results & Findings
- Total sales were calculated successfully
- Average, maximum, and minimum sales were identified
- Best-selling product was found using group analysis

## Conclusion
This project helped in understanding real-world data analysis using Pandas.
It demonstrates data loading, cleaning, analysis, and reporting.
